## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program validates `assets/entry.png` (PNG signature, at most 1 MiB, at most 1024 by 1024) and copies it to the output directory as `entry.png`. Standard library only, no network, and both runs write identical bytes.

## Files

- `main.py` — the entry program.
- `assets/entry.png` — the poster.
- `.makefun/owner.json` — the wallet the entry was signed with.
